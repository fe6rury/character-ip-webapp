# AI/클라우드 온캠퍼스 인턴십 (6팀) - 캐릭터 IP 유사도 판별 WepApp

## Windows 실행

1. 저장소를 내려받고 프로젝트 폴더에서 실행.cmd를 더블클릭
2. 실행 준비 완료 후, cmd 창에 Uvicorn running이 나오면 브라우저에서 http://127.0.0.1:8000 실행
3. 검사할 상품 사진을 웹 화면에 업로드 가능. 종료는 검은 창에서 Ctrl+C

저장소의 data 폴더에 학습된 인쇄 검출 모델과 10종 판별층, 공식 원본 100장 및 원본 임베딩이 들어 있습니다. 앱을 실행할 때 Colab 학습을 다시 할 필요가 없습니다.

- **김호진** : 고양고양이·갓평이·해봄이 데이터셋 구축, DINOv2 기반 10종 캐릭터 검색 웹앱 구현, 상품 변형 이미지 제작
- **문세연** : 부기·하모·랑랑이 데이터셋 구축, DINOv2 기반 10종 캐릭터 검색과 변형 데이터를 반영한 웹앱 구현
- **조윤경** : 조아용 데이터셋 구축, DINOv2 기반 판별 학습 및 YOLO 검출과 상품 변형을 반영한 웹앱 통합

## 영역 지정

이미지를 올리면 초기 버전과 동일하게 전체 사진을 분석합니다. 사진 위에서 원하는 부분을 드래그하고 **선택 영역 분석**을 누르면 그 부분만 잘라 기존 YOLO → DINOv2 → 학습 판별층 처리에 입력합니다. YOLO가 영역을 검출하지 못해도 선택 범위 전체를 비교합니다.

**전체 이미지 분석**으로 전체 사진을 다시 분석할 수 있으며, **선택 초기화**로 지정한 박스를 지울 수 있습니다. 캐릭터/굿즈 모드 구분은 없습니다. 모델 가중치와 판정 기준은 초기 버전 그대로입니다.

API: `POST /api/identify`의 선택 필드 `region=left,top,right,bottom`에 EXIF 방향 적용 후 이미지 기준 0~1 좌표를 보냅니다. 생략하면 전체 이미지를 분석합니다. 선택 영역은 최소 8×8픽셀이어야 합니다. 응답 `region`은 적용한 좌표이며 전체 이미지 분석 시 `null`입니다. 검출 박스는 분석 입력 범위에 대한 상대 좌표입니다.
