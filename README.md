# AI온캠 캐릭터 IP 유사도 판별

## Windows 실행

1. 저장소를 내려받고 프로젝트 폴더에서 실행.cmd를 더블클릭합니다.
2. 첫 실행에는 Python 3.12와 인터넷 연결이 필요합니다. 필요한 패키지와 DINOv2 사전학습 가중치를 준비합니다.
3. 검은 창에 Uvicorn running이 나오면 브라우저에서 http://127.0.0.1:8000 을 엽니다.
4. 검사할 상품 사진을 웹 화면에 올릴 수 있습니다. 종료는 검은 창에서 Ctrl+C입니다.

저장소의 data 폴더에 학습된 인쇄 검출 모델과 10종 판별층, 공식 원본 100장 및 원본 임베딩이 들어 있습니다. 앱을 실행할 때 Colab 학습을 다시 할 필요가 없습니다.

## 학습 데이터와 앱 동작

- 팀 데이터 10,122개 항목을 학습에 사용했습니다. OR/OG 100, EP 2,100, HP 4,131, HN 3,591, EN 200입니다.
- DINOv2는 사전학습 가중치를 고정해 특징을 뽑습니다. 그 특징을 입력으로 쓰는 10종 판별층을 팀 데이터로 학습했습니다. HN에는 비교 대상 캐릭터의 음성 라벨을 주었습니다. EN의 등록 캐릭터 90개 항목은 해당 캐릭터의 양성, 나머지 110개는 미등록 음성으로 처리했습니다. 완전히 같은 파일은 중복 가중치로 균형을 맞췄습니다.
- YOLO는 별도로 박스가 있는 상품 사진 39장으로 인쇄 위치를 학습했고 검증 14장으로 검출 기준을 골랐습니다. 사진 전체와 YOLO 검출 영역에 10종 판별층을 적용합니다. 비교 원본의 형태·색상 점수와 학습 모델 판별 점수를 보여줍니다.
- 팀 공유 드라이브는 읽기 전용으로 사용했습니다. 일부 EN 경로를 읽지 못한 경우 동일한 SHA-256의 공식 원본으로 해당 항목을 사용했습니다. 구체적인 입력 출처와 대응 경로는 전체학습_결과.json에 있습니다.

## 평가

원본이 같은 OG/EP를 함께 분리한 벤치마크에서 10종 정답 220/220장이 1위였습니다. 미등록 EN은 29/30장을 검수 기준 아래로 분류했습니다. 판별 기준 0.765은 별도 검증용 원본 그룹에서 선택했습니다. 이 수치는 별도 벤치마크 모델의 결과이고, 제출 가중치는 평가 설계를 마친 다음 팀 데이터 전체로 다시 학습한 모델입니다. 상품 사진 전체에서 판별 점수는 침해 확률이 아닙니다.

제출 앱의 상품 테스트에서는 정답이 1위인 사진 9/15장, 박스가 나온 사진 12/15장이었습니다.

| 유형 | 장수 | 박스 표시 | 정답 1위 |
|---|---:|---:|---:|
| 의류 | 8 | 7 | 6 |
| 머그컵 | 2 | 2 | 1 |
| 비닐 포장 | 2 | 2 | 2 |
| 펜 | 3 | 1 | 0 |

상품 테스트는 부기·갓평이의 기존 변형 예시로 제한됩니다. 특히 작은 펜 인쇄는 검출과 식별이 어렵습니다. 팀 내 전체 이미지의 범용 평가나 실제 침해 여부 판단에는 사용할 수 없습니다. 세부 결과는 전체학습_결과.json과 전체학습_실행검증.json에 기록했습니다.


## 학습 재현

training 폴더에 전체 판별층 학습 코드, YOLO 훈련 코드와 Colab 노트북을 보관합니다. 노트북 실행에 필요한 AI온캠_전체학습_입력.zip 및 AI온캠_Colab_입력.zip은 원본 완성본 ZIP에 있습니다. 팀 학습 이미지는 팀 공유 드라이브에서 권한이 있는 계정으로 읽습니다.
