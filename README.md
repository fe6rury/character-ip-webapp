# 캐릭터 IP 유사도 판별 Wep-App

## AI/클라우드 온캠퍼스 인턴십 
## 6조 프로젝트 - 캐릭터 IP유사도 판별

김병철 : 데이터셋(해치, 벼리, 뚜니)
김호진 : 데이터셋(고양고양이, 갓평이, 해봄이)
문세연 : 데이터셋(부기, 하모, 랑랑이)
조윤경 : 데이터셋(조아용)

## Windows 실행

1. 저장소를 내려받고 프로젝트 폴더에서 실행.cmd를 더블클릭
2. 실행 준비 완료 후, cmd 창에 Uvicorn running이 나오면 브라우저에서 http://127.0.0.1:8000 실행
3. 검사할 상품 사진을 웹 화면에 업로드 가능. 종료는 검은 창에서 Ctrl+C

저장소의 data 폴더에 학습된 인쇄 검출 모델과 10종 판별층, 공식 원본 100장 및 원본 임베딩이 들어 있습니다. 앱을 실행할 때 Colab 학습을 다시 할 필요가 없습니다.
